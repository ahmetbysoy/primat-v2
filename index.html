    🚀 Deployment

    Vercel + GitHub
    1) GitHub’a push (token’ı kodda tutma):
    git init && git add . && git commit -m "PRIMAT V2 - Para Mıknatısı"
    gh repo create primat-v2 --private --source=. --push // veya GitHub web'den private repo oluşturup remote ekle

    2) Vercel:
    vercel --prod // CLI seni login'e yönlendirir, token'ı .env'de tut
    vercel env add BINANCE_API_KEY // server-side only

    3) Env: .env.example'a bak. Asla ghp_ veya vcp_ token'ını git’e commit’leme. Leak olursa hemen revoke et (GitHub → Settings → Developer settings → Tokens → Revoke).
